# UI Icon Sources

The SVG files in this directory are derived from Google's Material Symbols collection and are used to generate the RAW565 status icons displayed by the Wi-Fi Radio Project.

The project currently uses the following Material Symbols:

- Wi-Fi
- Wi-Fi Off
- Bookmark Stacks
- Import Contacts
- Router
- Router Off
